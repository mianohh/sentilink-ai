## 🛠️ Setup Instructions
1. Clone/Download this repository.  
2. Insert database.sql into MySQL server.  
3. Modify config.php with database configuration.  
4. Place and upload all the files to a live or local server with PHP.  
5. To begin using the prototype, access the index.php.  
✅ Optional: Customize testnet wallet in `/api/blockchain.php` (under active development).
